# Simple Tic Tac Toe

A classic Tic Tac Toe game built with React and Vite.

<img width="520" height="619" alt="Image" src="https://github.com/user-attachments/assets/c9f1ef65-afa7-4325-b950-2ac20087035e" />

## Features

- Interactive 3x3 board
- Automatic winner and draw detection
- Confetti animation 🎉 when you win the game
- Result modal with the game outcome and a reset option
- Automatic game saving in the browser (localStorage), so if you reload the page the game continues where you left off
- Visual turn indicator (X or O)

## Tech stack

- React
- Vite
- canvas-confetti

## Run locally

Clone the repository and install the dependencies:

\`\`\`bash
npm install
\`\`\`

Start the development server:

\`\`\`bash
npm run dev
\`\`\`

Open the URL shown in the terminal (usually `http://localhost:5173`) in your browser.
