# React Practice

A collection of small React projects built to practice different concepts: Hooks, Context API, TypeScript, external APIs, and AI integration.

## Projects

### 1. Simple Tic Tac Toe
Classic Tic Tac Toe game with winner/draw detection, confetti animation, and game state saved in localStorage.

### 2. Movie Search App
A movie search tool consuming the OMDb API, with debounced search, input validation, and sorting.

### 3. React Shop
A shopping cart practice app using Context API and useReducer for global state, with product filters and cart persistence.

### 4. Todo App with TypeScript
A TodoMVC-style app focused on practicing TypeScript: strong typing, utility types, and typed component props.

### 5. AI Translator
A Google Translate-style app that uses an AI language model (via the Groq API) to translate text in real time, with text-to-speech and clipboard support.

### 6. React Query Users
A user directory with infinite scrolling, sorting, and filtering, built with TanStack React Query on top of a paginated public API.

## Tech stack overview

React · TypeScript · Vite · Context API · TanStack React Query · React Bootstrap
